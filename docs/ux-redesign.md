# Skilly 0.7.2: план как постоянное рабочее пространство
+
+Главная задача — собрать и оптимизировать очередь обучения. Пользователь работает с одним планом, а не проходит набор страниц. Оптимизация выбирает порядок, remap и учебные импланты; персональная адаптация учитывает состояние персонажа, не заменяя общий расчёт.
+
+## Исправление структуры после обратной связи
+
+В версии 0.7 консультация с Claude Code Opus 5.5 (medium) привела к библиотеке как странице и вкладкам «Цели / Маршрут / Книги и ускорение». Пользователь отверг эту структуру: она раздробила основную задачу и добавила ненужные переходы. В 0.7.2 боковая навигация и эти вкладки удалены.
+
+## Приоритеты и размещение
+
+1. **План и очередь** постоянно занимают основную область окна. Remap и покупки имплантов — строки очереди. Название, выбранный персонаж, время, SP и выигрыш видны сверху.
+2. **Копирование и импорт фита** доступны прямо над очередью. Remap, выбор имплантов, добавление навыков и целевые уровни находятся справа. Очередь остаётся на месте при редактировании; прокрутка у очереди и правой панели независимая.
+3. **Книги и способы ускорения** относятся к текущему плану. Оценка книг видна справа; подробности цен Jita и сравнение бустеров / инжекторов открываются по соседним кнопкам поверх плана.
+4. **Библиотека, группы и персонажи** — вспомогательные окна из верхней панели. Они не заменяют главный экран. Пустой запуск тоже показывает план с предложением вставить фит или добавить навык.
+5. **Технические подробности** раскрываются по месту: атрибуты и SP/ч в таблице, базовые атрибуты справа, метод расчёта под очередью. Графитовая палитра с бирюзовым акцентом сохранена; цвета пар атрибутов остаются предметным кодированием.
+
+## Сценарии
+
+- Фит → импорт в небольшом окне → навыки сразу появляются в текущем плане → автоматическая оптимизация → копирование.
+- Навык → название и целевой уровень справа → редактирование уровней там же → очередь обновляется без переключения представлений.
+- Персонаж → выбор сверху → проверка remap и имплантов справа → автоматическая адаптация. Возврат к общему контексту восстанавливает глобальный результат.
+- Несколько планов → «Планы и группы» → состав группы → общая очередь в том же рабочем пространстве.
+
+Черновик один и сохраняется автоматически. Библиотека обновляется явно кнопкой «Сохранить». При смене изменённого плана доступны сохранение, отказ от изменений и отмена. Формат данных и вычислительные API не изменены.
+
## Автоматическое обновление

Отдельного действия расчёта и выбора исходной очереди нет. Изменения целей, remap, имплантов, снимка ESI или персонажа запускают оптимизацию с короткой задержкой для объединения ввода. Пока актуального результата нет, очередь не подменяется исходной, а копирование и анализ отключены. Ответы для устаревшего состояния отбрасываются. Общая оптимизация и персональные адаптации хранятся отдельно; сохранённые актуальные результаты используются повторно. Сетевые ошибки повторяются автоматически с ограничением числа попыток и явным сообщением об ошибке.

## Версия 0.8: инжекторы в плане

Подробные столбцы очереди всегда видны, переключателя «Подробно» нет. «Инжекторов до цели» показывает число банок на оставшиеся обязательные цели после обучения до каждой строки; значения не суммируются. Источник — checkpoints расчёта с учётом общего SP и порогов эффективности. Тип банок, учёт свободных SP и дополнительная поправка общих SP находятся справа. Отдельного окна инжекторов нет. Окно бустеров содержит только их настройки; SP, дозы и эффективность сценария отображаются постоянно.
