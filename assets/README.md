# Accelerator catalog

Verified 2026-11-05 against the official public ESI `https://esi.evetech.net/universe/types/{id}`, compatibility date 2026-11-04.

Type IDs: 72238, 72239, 72240, 72241, 72242, 77919, 55826, 48582.

Dogma attributes 175–179 give the five attribute bonuses (equal for these items); attribute 330 is base booster duration in milliseconds, converted to hours. Requirements come from attributes 182 / 277. Known new-character accelerators with age restrictions are excluded from the built-in selection.

Biology (type 3405) uses attribute 66: +20% duration per level. Alchemist BY-805 (27147) and BY-810 (27148) use attribute 66 for +5% and +10% duration. These modifiers multiply Biology's duration factor.

See [CCP Cerebral Accelerators](https://support.eveonline.com/hc/en-us/articles/203217232-Cerebral-Accelerators) and [CCP skill injector rules](https://support.eveonline.com/hc/en-us/articles/207605005-Skill-Extractors-and-Skill-Injectors). These are informational calculations; they never activate or buy items in the game.
